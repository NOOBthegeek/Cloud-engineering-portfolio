Day 19 - Processes and Services

Commands learned:

ps aux
top
ps aux | grep httpd
sudo systemctl status httpd
sudo systemctl restart httpd
uptime
free -h
df -h

What I learned:

- Linux programs run as processes.
- Every process has a PID.
- top monitors system resources.
- systemctl manages services.
- Apache can be restarted without rebooting the server.
