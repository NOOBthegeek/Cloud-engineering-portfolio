## What I Learned

- Every file and directory in Linux has an owner, a group, and a set of permissions.
- Linux permissions determine who can read, write, or execute a file.
- The `ls -l` command displays detailed information about files, including permissions, owner, group, and file size.
- The `chmod` command is used to modify file and directory permissions using either symbolic or numeric notation.
- Numeric permissions are based on:
  - Read (`r`) = 4
  - Write (`w`) = 2
  - Execute (`x`) = 1
- Common permission values include:
  - **644** – Owner can read and write; group and others can only read.
  - **755** – Owner has full access; group and others can read and execute.
- The `chown` command changes the owner of a file or directory.
- Proper file permissions help secure Linux systems by preventing unauthorized access or modification.

---

## Key Concepts

### File Ownership

Every file has:
- **Owner (User)** – The user who owns the file.
- **Group** – Users who share access permissions.
- **Others** – Everyone else on the system.

### Permission Types

- **r** – Read
- **w** – Write
- **x** – Execute

### Common Linux Commands

- `ls -l` – View file permissions and ownership.
- `chmod` – Change file permissions.
- `chown` – Change file owner.
- `cat` – Display file contents.
- `touch` – Create an empty file.
- `echo` – Write text to a file.
