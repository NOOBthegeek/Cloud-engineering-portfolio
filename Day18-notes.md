Day 18 - Package Management

Commands:
cat /etc/os-release
sudo dnf check-update
sudo dnf install tree -y
tree --version
tree

What I learned:
- Amazon Linux 2023 uses DNF.
- sudo provides administrator privileges.
- DNF can check for updates.
- DNF installs packages.
- DNF knows when a package is already installed.
- The tree command displays directory structures.
