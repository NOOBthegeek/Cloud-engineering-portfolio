# Day 11 - Editing Files on a Linux Web Server

## What I Learned

- Apache serves files from /var/www/html
- index.html is the default webpage
- Changes to index.html appear immediately in the browser
- Linux servers can host websites directly

## Commands Used

cd /var/www/html

pwd

cat index.html

## Key Takeaway

A web server sends files from a directory to visitors through a browser.
