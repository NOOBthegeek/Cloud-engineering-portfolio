# Day 24 - Users and Groups

## Commands Learned

- cat /etc/passwd
- cat /etc/group
- groups
- sudo useradd
- sudo passwd
- id
- sudo userdel
- grep

## What I Learned

Linux stores user information in /etc/passwd and group information in /etc/group.

Users can belong to multiple groups that determine permissions.

New users can be created using useradd and assigned passwords using passwd.

The id command displays user and group IDs.

Users can be removed with userdel.

## Key Concepts

- Users authenticate to Linux systems.
- Groups simplify permission management.
- Administrative actions require sudo.
- User information is stored locally on the system.
