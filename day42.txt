```bash
journalctl -n 20
journalctl -f
journalctl -u sshd
journalctl -b
last
```

## Key Concepts

- `uptime` shows how long the system has been running and the load average.
- `top` displays running processes and real-time resource usage.
- `free -h` shows RAM and swap usage.
- `df -h` displays disk space usage.
- `du -sh` reports the size of a directory.
- `journalctl` is used to view and search system logs.
- `journalctl -u sshd` displays SSH service logs.
- `last` shows user login history.
