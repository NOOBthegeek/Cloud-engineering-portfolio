# Day 25 - File Ownership and Permissions

## Commands Learned

- ls -l
- chmod
- chown
- touch
- mkdir

## What I Learned

Linux uses permissions to control access to files and directories.

Each file has an owner and a group.

Permissions determine whether a user can read, write, or execute a file.

The chmod command changes permissions.

The chown command changes ownership.

## Key Concepts

- r = read
- w = write
- x = execute

Examples:

- 755 = rwxr-xr-x
- 600 = rw-------

Permissions are an important part of Linux security.
