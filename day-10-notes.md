# Day 10 - Apache Web Server

## What I Learned

- Installed Apache using dnf
- Started Apache with systemctl
- Enabled Apache to start automatically
- Opened HTTP port 80
- Hosted a webpage from an EC2 instance

## Commands Used

sudo dnf install httpd -y

sudo systemctl start httpd

sudo systemctl enable httpd

sudo systemctl status httpd

## Key Takeaway

A web server listens for requests and serves webpages to visitors.
