Commands Learned

* sudo dnf check-update
* sudo dnf upgrade -y
* sudo dnf install tree -y
* tree
* dnf list installed
* sudo dnf remove tree -y

What I Learned

Linux servers use package managers to install, update, and remove software.

Amazon Linux uses DNF (Dandified Yum) as its package manager. I learned how to check for available updates, upgrade installed packages, install new software, view installed packages, and remove software that is no longer needed.

I installed the tree package to visualize directory structures and later removed it using DNF.

Key Concepts

* DNF manages software packages on Amazon Linux.
* Software is installed from repositories.
* Regular updates improve security and system stability.
* Cloud engineers frequently install, update, and remove packages on servers.
* Package management is an essential server administration skill.
