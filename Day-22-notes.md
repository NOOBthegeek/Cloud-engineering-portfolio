## Commands Learned

- ssh
- hostname
- whoami
- uptime
- w
- last

## What I Learned

SSH (Secure Shell) allows secure remote administration of Linux servers.

I connected from my MacBook to an AWS EC2 instance using an SSH key.

Commands such as hostname, whoami, uptime, w, and last can be used to inspect server information and monitor activity.

## Key Concepts

- SSH provides encrypted remote access.
- Linux servers are commonly managed remotely.
- User activity and login history can be monitored.≈
